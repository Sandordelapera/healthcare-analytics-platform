# Data

This folder documents the dataset used in the Healthcare Analytics Platform.

The project was developed using an educational healthcare dataset containing information related to:

- Patient demographics
- Medical conditions
- Admissions and discharges
- Doctors and hospitals
- Insurance providers
- Billing amounts
- Medications
- Test results
- Room information
- Admission types

The dataset is used for educational and portfolio purposes.

The source dataset is not included in this repository unless redistribution rights are explicitly verified.
