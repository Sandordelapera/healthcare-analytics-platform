# SQL Components

This folder contains the PostgreSQL and SQL components developed for the Healthcare Analytics Platform.

Planned SQL files:

- `healthcare_db_setup.sql`
- `vw_healthcare_master.sql`
- `development_views.sql`

The final analytical architecture is centered on the PostgreSQL database `healthcare_db` and the centralized analytical View `vw_healthcare_master`.

The Views `vw_revenue_by_condition` and `vw_revenue_by_gender` were created during earlier learning and development stages and are retained only as development artifacts. They are not data sources for the five final executive dashboards.
