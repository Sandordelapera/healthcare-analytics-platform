# Architecture

This folder contains the architecture diagram for the Healthcare Analytics Platform.

Architecture image:

- `healthcare_analytics_architecture.png`

The architecture illustrates the end-to-end analytical flow:

**Healthcare Data → PostgreSQL `healthcare_db` → `vw_healthcare_master` → Tableau Analytics → KPIs & Worksheets → Executive Dashboards**

This diagram supports the technical documentation and provides a concise visual representation of the platform architecture for portfolio presentation.
